# BLDC电机驱动板 CAN通信协议 V1.0

## 1. 协议概述

| 项目 | 说明 |
|------|------|
| 物理层 | CAN 2.0A (标准帧, 11位ID) |
| 波特率 | 500Kbps (可配置) |
| 收发器 | SIT1044TK/3 |
| 通道 | CAN1 (主通道), CAN2 (辅助通道) |
| 数据格式 | Big Endian (高字节在前) |

---

## 2. 帧ID分配

### 2.1 发送帧 (驱动板 -> 上位机/主控)

| 帧ID | 帧名称 | 周期 | 说明 |
|-------|--------|------|------|
| 0x100 | 电机状态帧 | 50ms | 状态/转速/占空比 |
| 0x101 | 电压电流帧 | 50ms | 总线电压/电流/功率 |
| 0x102 | 温度编码器帧 | 50ms | 温度/编码器角度 |
| 0x103 | 故障信息帧 | 事件触发 | 故障发生时立即发送 |

### 2.2 接收帧 (上位机/主控 -> 驱动板)

| 帧ID | 帧名称 | 说明 |
|-------|--------|------|
| 0x200 | 控制指令帧 | 启停/占空比/方向控制 |
| 0x201 | 参数设置帧 | 参数修改 (预留) |
| 0x202 | 查询请求帧 | 请求驱动板发送指定数据 |

---

## 3. 发送帧数据格式

### 3.1 电机状态帧 (0x100)

**周期**: 50ms  
**长度**: 8字节

| 字节 | 字段 | 类型 | 比例因子 | 单位 | 说明 |
|------|------|------|----------|------|------|
| Byte0 | 电机状态 | uint8 | - | - | 见状态枚举表 |
| Byte1 | 保留 | - | - | - | 0x00 |
| Byte2 | 转速高字节 | uint16 | /1 | RPM | Big Endian |
| Byte3 | 转速低字节 | | | | |
| Byte4 | 占空比高字节 | uint16 | /1 | - | 0-999, Big Endian |
| Byte5 | 占空比低字节 | | | | |
| Byte6 | 保留 | - | - | - | 0x00 |
| Byte7 | 保留 | - | - | - | 0x00 |

**电机状态枚举**:

| 值 | 状态 | 说明 |
|----|------|------|
| 0x00 | STOP | 停止 |
| 0x01 | STARTING | 启动中 |
| 0x02 | RUNNING | 正常运行 |
| 0x03 | BRAKE | 制动中 |
| 0x04 | FAULT | 故障 |

**示例**: `10 00 00 C8 03 E7 00 00`
- 状态=RUNNING(0x02), 转速=200RPM, 占空比=999(100%)

### 3.2 电压电流帧 (0x101)

**周期**: 50ms  
**长度**: 8字节

| 字节 | 字段 | 类型 | 比例因子 | 单位 | 说明 |
|------|------|------|----------|------|------|
| Byte0 | 总线电压高字节 | uint16 | /10 | V | 精度0.1V, Big Endian |
| Byte1 | 总线电压低字节 | | | | |
| Byte2 | 相电流高字节 | int16 | /10 | A | 精度0.1A, 有符号, Big Endian |
| Byte3 | 相电流低字节 | | | | |
| Byte4 | 功率高字节 | uint16 | /10 | W | 精度0.1W, Big Endian |
| Byte5 | 功率低字节 | | | | |
| Byte6 | 保留 | - | - | - | 0x00 |
| Byte7 | 保留 | - | - | - | 0x00 |

**示例**: `01 18 00 C8 0C 1C 00 00`
- 电压=280(28.0V), 电流=200(20.0A), 功率=3100(310.0W)

### 3.3 温度编码器帧 (0x102)

**周期**: 50ms  
**长度**: 8字节

| 字节 | 字段 | 类型 | 比例因子 | 单位 | 说明 |
|------|------|------|----------|------|------|
| Byte0 | 温度高字节 | int16 | /10 | °C | 精度0.1°C, 有符号, Big Endian |
| Byte1 | 温度低字节 | | | | |
| Byte2 | 编码器角度高字节 | uint16 | /1 | - | 0-4095 (12位), Big Endian |
| Byte3 | 编码器角度低字节 | | | | |
| Byte4 | 保留 | - | - | - | 0x00 |
| Byte5 | 保留 | - | - | - | 0x00 |
| Byte6 | 保留 | - | - | - | 0x00 |
| Byte7 | 保留 | - | - | - | 0x00 |

**示例**: `01 5E 08 00 00 00 00 00`
- 温度=350(35.0°C), 编码器=2048(180°)

### 3.4 故障信息帧 (0x103)

**触发方式**: 故障发生时立即发送  
**长度**: 8字节

| 字节 | 字段 | 类型 | 说明 |
|------|------|------|------|
| Byte0 | 故障码 | uint8 | 见故障码表 |
| Byte1 | 霍尔状态 | uint8 | 当前霍尔值 (1-6有效) |
| Byte2 | 保留 | - | 0x00 |
| Byte3 | 保留 | - | 0x00 |
| Byte4 | 保留 | - | 0x00 |
| Byte5 | 保留 | - | 0x00 |
| Byte6 | 保留 | - | 0x00 |
| Byte7 | 保留 | - | 0x00 |

**故障码定义**:

| 故障码 | 名称 | 说明 |
|--------|------|------|
| 0x00 | 无故障 | 正常 |
| 0x01 | 霍尔传感器错误 | 霍尔值为0或7(无效) |
| 0x02 | 过流 | 电流超过20A阈值 |
| 0x03 | 过压 | 电压超过30V阈值 |
| 0x04 | 欠压 | 电压低于10V阈值 |
| 0x05 | 过温 | 温度超过80°C阈值 |
| 0x06 | I2C通信错误 | AS5600/INA226通信失败 |
| 0x07 | CAN通信错误 | CAN总线错误 |

## 4. 接收帧数据格式

### 4.1 控制指令帧 (0x200)

**长度**: 8字节

| 字节 | 字段 | 类型 | 说明 |
|------|------|------|------|
| Byte0 | 命令字 | uint8 | 见命令字表 |
| Byte1 | 参数高字节 | uint16 | Big Endian |
| Byte2 | 参数低字节 | | |
| Byte3 | 保留 | - | 0x00 |
| Byte4 | 保留 | - | 0x00 |
| Byte5 | 保留 | - | 0x00 |
| Byte6 | 保留 | - | 0x00 |
| Byte7 | 保留 | - | 0x00 |

**命令字定义**:

| 命令字 | 名称 | 参数 | 说明 |
|--------|------|------|------|
| 0x00 | STOP | 无 | 停止电机 |
| 0x01 | START | 无 | 启动电机 |
| 0x02 | BRAKE | 无 | 电机制动 |
| 0x03 | SET_DUTY | 0-999 | 设置占空比 |
| 0x04 | SET_DIR | 0=CW, 1=CCW | 设置旋转方向 |
| 0x05 | SET_SPEED | 目标RPM | 设置目标转速 (预留) |

**示例**:
- 启动电机: `01 00 00 00 00 00 00 00`
- 设置占空比50%: `03 01 F4 00 00 00 00 00` (500=0x01F4)
- 设置方向为逆时针: `04 00 01 00 00 00 00 00`

### 4.2 参数设置帧 (0x201)

**长度**: 8字节 (预留)

| 字节 | 字段 | 类型 | 说明 |
|------|------|------|------|
| Byte0 | 参数ID | uint8 | 参数编号 |
| Byte1 | 参数值 | 取决于参数 | |
| ... | ... | | |
| Byte7 | 保留 | - | 0x00 |

### 4.3 查询请求帧 (0x202)

**长度**: 8字节

| 字节 | 字段 | 类型 | 说明 |
|------|------|------|------|
| Byte0 | 查询类型 | uint8 | 见查询类型表 |
| Byte1 | 保留 | - | 0x00 |
| ... | ... | | |
| Byte7 | 保留 | - | 0x00 |

**查询类型定义**:

| 类型 | 名称 | 响应帧 |
|------|------|--------|
| 0x01 | 查询电机状态 | 发送0x100 |
| 0x02 | 查询电压电流 | 发送0x101 |
| 0x03 | 查询温度编码器 | 发送0x102 |
| 0xFF | 查询所有数据 | 发送0x100+0x101+0x102 |

**示例**: 查询所有数据: `FF 00 00 00 00 00 00 00`

## 5. 通信时序图

### 5.1 启动电机流程

```
上位机                          驱动板
  |                               |
  |--- [0x200] START ----------->|  发送启动指令
  |                               |  执行启动
  |<-- [0x100] 状态=STARTING ----|  返回启动中状态
  |                               |  等待霍尔信号
  |<-- [0x100] 状态=RUNNING -----|  进入运行状态
  |<-- [0x101] 电压电流数据 ------|  周期性发送
  |<-- [0x102] 温度编码器数据 ----|  周期性发送
```

### 5.2 故障处理流程

```
驱动板检测到故障
  |
  |--- [0x103] 故障码 --------->|  立即发送故障帧
  |  电机自动停止
  |--- [0x100] 状态=FAULT ----->|  状态变为故障
  |
  |  ... 等待上位机处理 ...
  |
  |<-- [0x200] STOP -----------|  上位机确认停止
  |  或
  |<-- [0x200] START ----------|  上位机尝试重启(故障清除后)
```

## 6. 保护阈值参数

| 参数 | 警告阈值 | 故障阈值 | 说明 |
|------|----------|----------|------|
| 总线电压 | - | >30V | 过压保护 |
| 总线电压 | - | <10V | 欠压保护 |
| 相电流 | - | >20A | 过流保护 |
| 电机温度 | >60°C | >80°C | 过温保护 |

---

## 7. 错误处理

1. **CAN发送失败**: 自动重试, 错误计数递增
2. **CAN接收超时**: 上位机应定期发送查询帧确认连接
3. **I2C通信失败**: 驱动板继续运行, 标记传感器数据无效
4. **霍尔传感器异常**: 立即停止电机, 发送故障帧

---

## 8. 扩展说明

- Byte6-Byte7为保留字段, 可用于后续协议扩展
- 参数设置帧(0x201)预留, 可扩展PID参数、保护阈值等在线配置
- 两个CAN通道发送相同数据, 可用于冗余或连接不同设备
