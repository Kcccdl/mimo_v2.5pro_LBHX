# 调试监视变量说明

## 1. 使用方法

1. Keil中编译工程
2. 进入Debug模式: **Debug → Start/Stop Debug Session** (或按 `Ctrl+F5`)
3. 打开Watch窗口: **View → Watch → Watch1**
4. 在Name列输入 `g_dbg`，回车
5. 点击 `g_dbg` 前的 `+` 号展开，即可看到所有变量
6. 按 `F5` 运行，变量值会实时刷新

> **提示**: Watch窗口支持修改变量值。双击Value列可直接写入，用于手动控制电机启停、设置占空比等调试操作。

---

## 2. 变量总览

所有变量定义在 `Debug_Monitor_t g_dbg` 结构体中，每10ms自动更新一次。

---

## 3. 霍尔传感器变量

| 变量名 | 类型 | 范围 | 说明 |
|--------|------|------|------|
| `hall_raw` | uint8 | 0-7 | 三路霍尔组合值 (bit2=HA, bit1=HB, bit0=HC) |
| `hall_a` | uint8 | 0/1 | HA电平 (PA0) |
| `hall_b` | uint8 | 0/1 | HB电平 (PA1) |
| `hall_c` | uint8 | 0/1 | HC电平 (PA2) |

**hall_raw 有效值对照表**:

| hall_raw | HA | HB | HC | 对应电角度 |
|----------|----|----|-----|-----------|
| 1 | 0 | 0 | 1 | 0°-60° |
| 2 | 0 | 1 | 0 | 60°-120° |
| 3 | 0 | 1 | 1 | 120°-180° |
| 4 | 1 | 0 | 0 | 180°-240° |
| 5 | 1 | 0 | 1 | 240°-300° |
| 6 | 1 | 1 | 0 | 300°-360° |
| 0 | 0 | 0 | 0 | **异常** |
| 7 | 1 | 1 | 1 | **异常** |

**调试技巧**:
- 手动旋转电机轴，观察 `hall_raw` 是否在1-6之间循环变化
- 如果 `hall_raw` 始终为0或7，说明霍尔传感器接线有问题

## 4. 电机状态变量

| 变量名 | 类型 | 范围 | 说明 |
|--------|------|------|------|
| `motor_state` | uint8 | 0-4 | 电机运行状态 |
| `comm_step` | uint8 | 0-5 | 当前换相步骤 |
| `duty_cycle` | uint16 | 0-999 | 当前实际占空比 (渐变中的实时值) |
| `target_duty` | uint16 | 0-999 | 目标占空比 (CAN指令设定的值) |
| `rpm` | uint16 | 0-65535 | 电机转速 (RPM) |
| `direction` | uint8 | 0/1 | 旋转方向 |

**motor_state 枚举**:

| 值 | 状态 | 说明 |
|----|------|------|
| 0 | STOP | 停止，所有输出关闭 |
| 1 | STARTING | 启动中，等待霍尔信号 |
| 2 | RUNNING | 正常运行 |
| 3 | BRAKE | 制动中，低边全开短路制动 |
| 4 | FAULT | 故障停机，需清除故障后才能重启 |

**comm_step 换相步骤**:

| 值 | PWM相 | 说明 |
|----|-------|------|
| 0 | U相PWM | U高边PWM, V低边常开 |
| 1 | U相PWM | U高边PWM, W低边常开 |
| 2 | V相PWM | V高边PWM, W低边常开 |
| 3 | V相PWM | V高边PWM, U低边常开 |
| 4 | W相PWM | W高边PWM, U低边常开 |
| 5 | W相PWM | W高边PWM, V低边常开 |

**调试技巧**:
- 观察 `duty_cycle` 是否平滑趋近 `target_duty`（每ms变化1）
- 运行时 `comm_step` 应随 `hall_raw` 变化而跳变
- `rpm` 在低速时可能跳变较大，属正常现象

## 5. 电压电流功率变量 (INA226)

| 变量名 | 类型 | 单位 | 说明 |
|--------|------|------|------|
| `bus_voltage` | float | V | 总线电压 |
| `phase_current` | float | A | 相电流 (有符号，负值表示反向) |
| `power` | float | W | 功率 = 电压 × 电流 |

**正常范围参考 (28V/20A系统)**:

| 变量 | 空载 | 轻载 | 满载 | 故障阈值 |
|------|------|------|------|----------|
| `bus_voltage` | 24-28V | 23-28V | 22-28V | <10V 或 >30V |
| `phase_current` | 0-0.5A | 1-5A | 5-15A | >20A |
| `power` | 0-10W | 20-100W | 100-400W | - |

**调试技巧**:
- 空载时 `phase_current` 应接近0，如果偏大说明有漏电或传感器偏移
- 可观察 `power` 计算效率: 效率 = 机械功率 / 电功率

---

## 6. 温度变量 (NTC)

| 变量名 | 类型 | 单位 | 说明 |
|--------|------|------|------|
| `temperature` | float | °C | 电机/驱动板温度 |

**温度阈值**:

| 范围 | 状态 | 说明 |
|------|------|------|
| < 40°C | 正常 | 安全运行 |
| 40-60°C | 偏高 | 正常，注意散热 |
| 60-80°C | 警告 | warning_flag=1，CAN发送警告 |
| > 80°C | 故障 | fault_code=5，自动停机 |

**调试技巧**:
- 用手触摸NTC传感器，观察 `temperature` 是否上升
- 如果读数为 -99°C，说明ADC读取失败

---

## 7. 编码器变量 (AS5600)

| 变量名 | 类型 | 单位 | 说明 |
|--------|------|------|------|
| `encoder_raw` | uint16 | - | 原始角度值 (12位, 0-4095) |
| `encoder_deg` | float | ° | 角度 (0.0-360.0°) |
| `encoder_mag` | uint16 | - | 磁场强度 (越大越好，正常>1000) |

**encoder_raw 与角度对应**:

| encoder_raw | 角度 | 说明 |
|-------------|------|------|
| 0 | 0° | 零位 |
| 1024 | 90° | |
| 2048 | 180° | |
| 3072 | 270° | |
| 4095 | 359.9° | |

**调试技巧**:
- 缓慢旋转电机，`encoder_deg` 应平滑连续变化
- 如果 `encoder_deg` 跳变或为0，检查磁铁与AS5600的距离（建议0.5-3mm）
- `encoder_mag` 过小说明磁场太弱，磁铁太远

## 8. 故障变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `fault_code` | uint8 | 当前故障码 (0=无故障) |
| `warning_flag` | uint8 | 温度警告标志 (0=正常, 1=警告) |

**fault_code 故障码表**:

| 故障码 | 名称 | 原因 | 恢复方法 |
|--------|------|------|----------|
| 0 | 无故障 | 正常 | - |
| 1 | 霍尔错误 | 霍尔值为0或7 | 检查霍尔接线 |
| 2 | 过流 | 电流 > 20A | 检查负载/电机 |
| 3 | 过压 | 电压 > 30V | 检查电源 |
| 4 | 欠压 | 电压 < 10V | 检查电源电量 |
| 5 | 过温 | 温度 > 80°C | 等待降温 |
| 6 | I2C错误 | AS5600/INA226通信失败 | 检查I2C接线 |
| 7 | CAN错误 | CAN总线错误 | 检查CAN终端电阻 |

**调试技巧**:
- 故障发生后，`motor_state` 自动变为4 (FAULT)
- 可通过Watch窗口双击 `fault_code` 的值，改为0来清除故障
- 双击 `motor_state` 改为2可尝试强制运行（排查问题时使用）

---

## 9. CAN通信统计

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `can1_tx_cnt` | uint32 | CAN1发送帧计数 |
| `can1_rx_cnt` | uint32 | CAN1接收帧计数 |
| `can2_tx_cnt` | uint32 | CAN2发送帧计数 |
| `can2_rx_cnt` | uint32 | CAN2接收帧计数 |

**调试技巧**:
- `can1_tx_cnt` 每50ms增加3（状态帧+电压帧+温度帧）
- `can1_rx_cnt` 不变说明没有收到上位机指令
- 两个CAN通道的计数应独立变化

## 10. ADC原始值

| 变量名 | 类型 | 单位 | 说明 |
|--------|------|------|------|
| `adc_raw` | uint16 | - | ADC原始值 (12位, 0-4095) |
| `adc_voltage` | float | V | ADC采样电压 (0-3.3V) |

**ADC值与温度对应关系 (10K NTC, B=3950, 10K分压)**:

| 温度 | NTC阻值 | 分压电压 | ADC值 |
|------|---------|----------|-------|
| 0°C | 32.65K | 0.76V | 944 |
| 25°C | 10K | 1.65V | 2048 |
| 50°C | 3.6K | 2.42V | 3003 |
| 80°C | 1.27K | 2.92V | 3620 |
| 100°C | 0.67K | 3.10V | 3843 |

**调试技巧**:
- `adc_raw` 应在合理范围内（约900-3800），接近0或4095说明接线错误
- `adc_voltage` 直接反映分压点电压，可用于验证NTC电路

## 11. Watch窗口使用技巧

### 打开多个Watch窗口
- 可以同时打开 Watch1、Watch2、Watch3 多个窗口
- 不同窗口放不同分组的变量，方便对比

### 按分组观察
在Watch窗口中直接输入具体变量路径:
```
g_dbg.hall_raw          -- 只看霍尔值
g_dbg.motor_state       -- 只看电机状态
g_dbg.bus_voltage       -- 只看电压
g_dbg.phase_current     -- 只看电流
g_dbg.temperature       -- 只看温度
g_dbg.encoder_deg       -- 只看编码器角度
g_dbg.fault_code        -- 只看故障码
```

### 修改变量值调试
双击Value列可直接写入:
- 双击 `g_dbg.target_duty` 写入 `500` → 设置50%占空比
- 双击 `g_dbg.fault_code` 写入 `0` → 清除故障
- 双击 `g_dbg.motor_state` 写入 `2` → 强制设为运行状态

### 实时曲线 (Logic Analyzer)
1. Debug模式下: **View → Analysis Windows → Logic Analyzer**
2. 点击左上角 **Setup** → **Add** → 输入变量名如 `g_dbg.rpm`
3. 运行后可看到变量随时间变化的波形
4. 推荐添加: `g_dbg.rpm`, `g_dbg.phase_current`, `g_dbg.temperature`
